# אישורי הגעה לאירוע

אתר פשוט לאישורי הגעה: כל מוזמן ממלא שם, טלפון, האם מגיע, **כמה גברים וכמה נשים**.
דף ניהול מציג סיכום (גברים / נשים / סה"כ) ורשימה מלאה, עם הורדה לאקסל.

- **אתר** – GitHub Pages (חינם), נפרס אוטומטית בכל `push` ל-`main`.
- **שמירת נתונים** – Google Sheets דרך Google Apps Script (חינם, בחשבון Google שלכם).

```
index.html          טופס אישור הגעה למוזמנים
admin.html          דף ניהול וסיכומים (מוגן בקוד מנהל)
config.js           פרטי האירוע + כתובת השרת  ← הקובץ היחיד לעריכה
style.css           עיצוב
apps-script/Code.gs קוד השרת להדבקה ב-Google Apps Script
```

## שלב 1 – חיבור Google Sheets (כ-3 דקות, פעם אחת)

1. צרו גיליון חדש ב-[sheets.new](https://sheets.new) ותנו לו שם (למשל "אישורי הגעה").
2. בתפריט: **הרחבות ← Apps Script**.
3. מחקו את התוכן הקיים, הדביקו את כל התוכן של `apps-script/Code.gs`, ושמרו.
4. בחרו בפונקציה `setup` בסרגל העליון ולחצו **הפעלה**. אשרו את ההרשאות.
   ביומן ההרצה יופיע **קוד המנהל** – שמרו אותו.
5. **פריסה ← פריסה חדשה ← אפליקציית אינטרנט**:
   - ביצוע בתור: **אני**
   - למי יש גישה: **כל אחד**
6. העתיקו את הכתובת (מסתיימת ב-`/exec`).

## שלב 2 – הגדרת האירוע

ערכו את `config.js`: שם האירוע, תאריך, שעה, מקום, והדביקו את הכתובת בשדה `apiUrl`.
לאחר `push` האתר מתעדכן תוך כדקה.

## שלב 3 – שליחת ההזמנה

- קישור כללי: `https://<user>.github.io/event-rsvp/`
- קישור אישי עם שם ממולא מראש: `https://<user>.github.io/event-rsvp/?name=משפחת לוי`
- דף ניהול: `https://<user>.github.io/event-rsvp/admin.html` (נדרש קוד המנהל)

מוזמן שממלא שוב עם אותו מספר טלפון – התשובה הקודמת שלו מתעדכנת (אין כפילויות).
כל הנתונים נמצאים גם ישירות בגיליון ה-Google Sheets.

## הפעלת GitHub Pages

ב-GitHub: **Settings ← Pages ← Source: GitHub Actions**. (ה-workflow מנסה להפעיל זאת אוטומטית.)
